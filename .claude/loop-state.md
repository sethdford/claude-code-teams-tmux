## Specification: Intelligent Retry Strategy Engine with Failure Pattern Recognition

### Goals
- Failure classification system categorizes failures into: recoverable-transient, recoverable-escalation, context-exhausted, unrecoverable

- Integration: sw-loop.sh and sw-daemon.sh invoke engine before retry attempts
- Metrics: tracks retry success rate by strategy, logged to events.jsonl
